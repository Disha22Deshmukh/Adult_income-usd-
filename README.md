# Adult Income Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Adult Income Dataset from the UCI Machine Learning Repository. The main objective is to analyze how demographic, educational, employment, and financial factors are related to individual income levels.

## Dataset
- **Source:** UCI Machine Learning Repository – Adult Dataset
- **Total Records:** 48,842
- **Total Attributes:** 15 original features
- **Target Variable:** Income (`<=50K` and `>50K`)

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Activities
- Data loading and preprocessing
- Data cleaning and handling missing values
- Exploratory Data Analysis (EDA)
- Statistical analysis of numerical and categorical features
- Feature engineering (`high_income`, `hours_group`, and `net_capital`)
- Outlier detection using the IQR method
- Data visualization and correlation analysis

## Key Findings
- Approximately 76.07% of individuals earn $50K or less.
- Approximately 23.93% earn more than $50K.
- Average age is 38.64 years.
- Average working hours are 40.42 hours per week.
- Capital gain and capital loss have median values of zero.

## Project Objective
The goal is to identify patterns and understand the relationship between education, occupation, age, working hours, and other attributes with individual income levels through data analysis and visualization.
